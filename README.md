## 简介

此仓库的灵感来源于「鸿镜」——一个类似安卓Scrcpy，面向 OpenHarmony 设备的投屏开发调试工具，但是「鸿镜」仓库的 hap 程序适配的是 arm 架构的 OpenHarmony，而 K3 运行的是 risc v 架构的 OpenHarmony，因此，此仓库复用了「鸿镜」的 Windows 和 MacOS 客户端，另外编写了一套适用于 K3 的板端程序，使其能在板上运行，将画面传输至电脑，并将电脑下发的指令传输至 K3 后运行。

## 使用

1. 下载对应电脑的「鸿镜」APP。Windows 电脑下载 HongJing-Setup-1.0.3.exe，Mac 下载 HongJing-1.0.3.dmg，之后完成对应程序的安装。

2. 下载 release 中的 screen-mirroring.zip，解压。

3. 使用数据线连接 K3 调试口和电脑。

4. Windows 双击运行其中的 screen-mirroring.cmd，Mac 双击运行其中的 screen-mirroring.command。

5. 在弹出的交互式终端内输入数字 1、2 选择投屏分辨率（默认是1080P，需要降低分辨率时可以调到 720P），回车确认。

   **注意：每次切换分辨率（即 1080P -> 720P、720P -> 1080P）时，需要重启开发板。但重启时开发板可能会有一个 Bug，详情见[开机时的 Bug](#开机时的-bug可能有)。**

6. 输入数字 1、2 选择编码模式（默认是硬件编码），回车确认。

   **注意：更换编码模式不需要重启开发板。只需在「鸿镜」APP 内断开连接，再次运行 screen-mirroring.cmd（或screen-mirroring.command）脚本，重新选择编码模式，之后再进入「鸿镜」APP连接即可。**

7. 等待命令执行完成。

8. 打开「鸿镜」APP ，点击左上角的「刷新设备列表」按钮，然后选中 K3，点击连接按钮。

9. 点击右侧「设备控制」里的「主页」，进入 K3 主页。

不同编码模式的说明如下：

| 编码选项 | 板端工作方式 | 「鸿镜」APP内显示 |
| --- | --- | --- |
| 硬件编码 | K3 视频编码单元压缩 H.264 | H264 |
| 软件编码 | K3 的 CPU 将每帧独立压缩成 JPEG | JPEG |

## 目前可用的功能
查看屏幕镜像、用鼠标模拟手指操控屏幕、设备控制（返回上一级和返回主页）、文本输入（「鸿镜」APP 右侧）

## 开机时的 Bug（可能有）

当上电时，如果 K3 的 USB 调试口连接着电脑，那么开机后电脑将无法成功连接开发板。需要在重启或开机前断开与电脑的物理连接（拔线），才可以在开机后成功识别。

具体原因为：USB 有两种角色，一种是 Host，另一种是 Device。正常情况下，开发板应该处于 Device 状态，电脑应该处于 Host 状态，此时电脑可以通过 hdc 调试开发板。但在连接电脑时开机，开发板被错误地初始化为 Host 模式，导致电脑无法识别到开发板，因此也没有办法使用 hdc。
